## 🌍 Languages

Clarify supports 7 languages:
- 🇺🇸 English
- 🇧🇷 Português (Brasil)
- 🇪🇸 Español
- 🇫🇷 Français
- 🇩🇪 Deutsch
- 🇨🇳 中文 (简体)
- 🇯🇵 日本語

Switch language in: `Settings → Language`
