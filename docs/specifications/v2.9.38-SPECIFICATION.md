## 🎯 Contexto e Motivação {#contexto}

### Problema

**Protocolo Simplicidade 3 - Etapa 10.6 (CI/CD Quality Gates) é OBRIGATÓRIA**:
- Solo developer em produção precisa de validação automática 24/7
- Memória humana falha (esquecemos de rodar testes antes de commit)
- Pressão de entrega cria tentação de skip testes
- Regressions silenciosas afetam usuários reais
- Sem automação, qualidade degrada ao longo do tempo

**Estado Anterior**:
- ✅ Pre-commit hooks existiam (`.pre-commit-config.yaml` - black, isort, pylint)
- ❌ GitHub Actions CI/CD não implementado
- ❌ Code coverage não rastreado
- ❌ Nenhuma validação automática em push/PR
- ❌ 23 imports incorretos em `src/gui/*.py` (relative imports beyond top-level)

**Impacto**:
- Bugs podem ser merged sem detecção
- Coverage não visível (impossível melhorar o que não se mede)
- Equipe (1 pessoa) não tem rede de segurança
- Confiança em produção baixa

### Solução

**Implementar CI/CD completo**:
1. GitHub Actions workflow com 2 jobs (test + lint)
2. Code coverage reporting com pytest-cov
3. Codecov.io integration para tracking histórico
4. README badges para visibilidade
5. Corrigir bugs de import que impediam testes

**Benefícios**:
- ✅ Validação automática em cada commit/PR
- ✅ Coverage tracking evolution (gráficos, trends)
- ✅ Pre-merge quality gates (fail se <80% coverage)
- ✅ Confidence em produção (catch bugs early)
- ✅ Setup one-time (~30min), automático forever

### Funcionalidades Implementadas

#### 1. GitHub Actions CI/CD Workflow

**Arquivo**: `.github/workflows/ci.yml` (122 linhas)

**Job 1: Test**
- **Matrix**: Python 3.12 (expansível para 3.12, 3.13)
- **Triggers**: push (main, develop), pull_request, manual dispatch
- **Steps**:
  1. Checkout code (actions/checkout@v4)
  2. Setup Python 3.12 com pip cache
  3. Install system deps (Qt libraries para headless testing)
  4. Install Python deps (PySide6, pytest, pytest-cov, pytest-timeout, pytest-qt, black, pylint, isort)
  5. Run tests com coverage:
     ```bash
     QT_QPA_PLATFORM=offscreen pytest tests/ \
       -v --timeout=30 \
       --cov=src --cov-report=term-missing --cov-report=html --cov-report=xml \
       --cov-fail-under=80
     ```
  6. Upload coverage XML para Codecov
  7. Upload coverage HTML como artifact (30 days retention)

**Job 2: Lint**
- **Python**: 3.12
- **Tool**: Pylint com config do pyproject.toml
- **Thresholds**: >9.0 score (fail under)
- **Disables**: C0111, C0103, R0913, R0902, R0914, R0915, C0301, W0107, R1705, R0912, W0212, C0302

**Environment**:
- `QT_QPA_PLATFORM=offscreen` → Headless GUI testing (sem display)
- `QT_QPA_PLUGIN_PATH=""` → Evita conflitos de plugins Qt
- `DISPLAY=""` → Confirma modo headless
- `CODECOV_TOKEN` → GitHub secret para upload (não exposto)

#### 2. Code Coverage Configuration

**Arquivo**: `.coveragerc` (60 linhas)

**[run] section**:
- `source = src` → Apenas código fonte (não tests/)
- `branch = True` → Coverage de branches (if/else paths)
- `omit` → Exclusões:
  - `*/tests/*`, `*/test_*.py` → Testes não contam para coverage
  - `*/__pycache__/*` → Cache Python
  - `*/old/*`, `*/add/*`, `*/archive/*` → Código legado/experimental
  - `*/.venv/*`, `*/venv/*` → Virtual environments
  - `setup.py` → Script de instalação

**[report] section**:
- `precision = 2` → 2 casas decimais (93.45%)
- `show_missing = True` → Mostra linhas não cobertas
- `skip_covered = False` → Mostra arquivos 100% também
- `skip_empty = True` → Ignora arquivos vazios
- `exclude_lines` → Linhas ignoradas:
  - `pragma: no cover` → Exclusão manual
  - `def __repr__`, `def __str__` → Debug methods
  - `raise AssertionError`, `raise NotImplementedError` → Defensive code
  - `if __name__ == .__main__.:` → Entry points
  - `if TYPE_CHECKING:` → Type hints runtime check
  - `@abstractmethod`, `@abc.abstractmethod` → Interfaces
  - `pass`, `...` → Placeholders

**[html] section**:
- `directory = htmlcov` → Output HTML interativo
- `title = Clarify Code Coverage Report` → Título customizado

**[xml] / [json] sections**:
- `output = coverage.xml` → Para Codecov upload

### Etapa 6: Implementação (250+ linhas)

**Task 1: GitHub Actions CI/CD (122 linhas)**
```yaml
# .github/workflows/ci.yml
name: CI
on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]
  workflow_dispatch:

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ['3.12']
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
          cache: 'pip'
      - name: Install system dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libxcb-cursor0 ... (14 libs Qt)
      - name: Install Python deps
        run: |
          pip install PySide6>=6.9.3
          pip install pytest>=8.0 pytest-cov>=4.1 pytest-timeout>=2.2 pytest-qt>=4.3
          pip install black>=23.0 pylint>=3.0 isort>=5.0
      - name: Run tests
        env:
          QT_QPA_PLATFORM: offscreen
        run: |
          pytest tests/ -v --timeout=30 --cov=src --cov-report=xml --cov-fail-under=80
      - uses: codecov/codecov-action@v4
        with:
          file: ./coverage.xml
        env:
          CODECOV_TOKEN: ${{ secrets.CODECOV_TOKEN }}
      - uses: actions/upload-artifact@v4
        with:
          name: coverage-report
          path: htmlcov/
          retention-days: 30
  
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - name: Run Pylint
        run: |
          pylint src/ --fail-under=9.0 --output-format=colorized
```
