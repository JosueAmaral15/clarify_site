## 📋 Objetivo

Adicionar capacidade de **remover objetos JSON duplicados** no JSON Rewriter, detectando automaticamente objetos com valores idênticos ou similares e mantendo apenas a primeira ocorrência (linha menor no arquivo fonte).

---

## 🎯 Problema Resolvido

### **Antes** (sem Remove Duplicate Objects):
- Arquivos JSON com objetos duplicados espalhados (ex: `user` e `author` com mesmos valores)
- Processamento manual necessário para identificar duplicatas
- Desperdício de espaço em arquivos grandes
- Inconsistências em configurações repetidas

### **Depois** (com Remove Duplicate Objects):
- **Detecção automática** de objetos com valores idênticos
- **Threshold configurável** (50-100%): permite matching parcial
- **Modo Remove** (default): deleta duplicatas, mantém primeiro
- **Modo Reference** (opcional): substitui por `$ref:path.to.original`
- **Include Arrays**: opcionalmente compara arrays também
- **Statistics**: feedback detalhado de quantos objetos foram removidos

## 🏗️ Arquitetura

### **1. Core Logic** (`src/rewriter/operations.py`)

**Função**: `remove_duplicate_objects(node, threshold, include_arrays, mode)`

```python
def remove_duplicate_objects(
    node: JSONNode,
    threshold: float = 1.0,
    include_arrays: bool = False,
    mode: str = 'remove'
) -> Tuple[JSONNode, int, dict]:
    """
    Remove duplicate objects based on value equality.
    
    Args:
        node: JSONNode to process
        threshold: Similarity threshold (0.0-1.0). 1.0 = exact match only
        include_arrays: If True, also compare arrays for duplicates
        mode: 'remove' (delete duplicates) or 'reference' (replace with $ref:path)
    
    Returns:
        Tuple of (processed_node, removed_count, stats_dict)
    """
```

**Algoritmo**:

1. **Percorrer recursivamente** todos os nós do JSON tree
2. **Para cada Obj** (objeto):
   - Calcular `frozen_val = freeze(obj)` para hashing
   - Procurar em `seen_objects` por objetos já visitados
   - **Calcular similarity score**:
     ```python
     def calculate_similarity(obj1, obj2):
         # Para Obj: % de campos que batem
         # Para list: 1.0 se idênticos, 0.0 caso contrário
         # Para primitives: 1.0 se iguais, 0.0 caso contrário
     ```
   - Se `similarity >= threshold`:
     - **Mode 'remove'**: retornar `None` (remove objeto)
     - **Mode 'reference'**: retornar `"$ref:path"` (cria referência)
     - Incrementar `removed_count`
     - Registrar em `stats_dict`
   - Se não é duplicata:
     - Adicionar a `seen_objects[frozen_val] = (path, key, obj)`
     - Processar children recursivamente
3. **Para arrays** (se `include_arrays=True`):
   - Mesma lógica de deduplicação
   - Arrays devem ser 100% idênticos (sem similarity parcial)
4. **Para primitives**:
   - Não fazer deduplicação (manter todos)

**Estruturas de Dados**:

```python
seen_objects: Dict[Any, Tuple[str, str, JSONNode]]
# Key: frozen value (tuple immutável)
# Value: (path, key, original_obj)

stats_dict = {
    'duplicates_found': [
        {'removed_path': 'root.author', 'kept_path': 'root.user', 'similarity': 1.0}
    ],
    'references_created': [
        {'removed_path': 'root.duplicate', 'reference_to': 'root.original', 'similarity': 1.0}
    ],
    'kept_objects': [
        {'path': 'root.user', 'frozen_signature': '(("name", "John"), ...)'}
    ]
}
```

## ⚠️ Edge Cases Tratados

### **1. Empty Objects**
```python
{'empty1': Obj([]), 'empty2': Obj([])}
# → Remove one (empty objects são considerados duplicatas)
```

### **2. Null Values**
```python
{'obj1': {'value': None}, 'obj2': {'value': None}}
# → Remove one (null é valor válido para comparison)
```

### **3. Nested Duplicates**
```python
{'config': {'db1': {'host': 'localhost'}, 'db2': {'host': 'localhost'}}}
# → Detecta duplicatas em qualquer profundidade
```

### **4. Arrays Excluded by Default**
```python
{'list1': [1,2,3], 'list2': [1,2,3]}
# → Keep both (unless include_arrays=True)
```

### **5. Primitives Never Deduplicated**
```python
{'value1': 42, 'value2': 42}
# → Keep both (primitives não são objetos)
```

## 📚 Padrões de Design Aplicados

### **GoF Patterns**:

1. **Strategy** (GoF):
   - Diferentes estratégias de deduplicação (remove vs reference)
   - `mode` parameter seleciona strategy

2. **Visitor** (GoF):
   - `process_node()` visita recursivamente cada nó do tree
   - Processa Obj, list, primitives de forma polimórfica

3. **Flyweight** (GoF):
   - `freeze()` cria representação imutável compartilhável
   - `seen_objects` usa frozen values como keys

4. **Template Method** (GoF):
   - Algoritmo geral de traversal fixo
   - Subpassos customizáveis (similarity calculation, mode handling)

### **GRASP Patterns**:

1. **Information Expert** (GRASP):
   - `calculate_similarity()` encapsula lógica de comparison
   - `remove_duplicate_objects()` conhece estrutura do JSON tree

2. **Low Coupling** (GRASP):
   - Função standalone, não depende de GUI
   - Stats retornados via dict (não side effects)

3. **High Cohesion** (GRASP):
   - Função foca exclusivamente em deduplicação
   - Helpers internos (`calculate_similarity`, `process_node`)

4. **Protected Variations** (GRASP):
   - Interface estável (`threshold`, `mode`, `include_arrays`)
   - Implementação interna pode mudar sem afetar chamadores

## 🎓 Lições Aprendidas

### **1. Similarity Calculation is Tricky**
- Inicialmente usei apenas `freeze()` para exact match
- Adicionar threshold requereu `calculate_similarity()` separada
- Arrays devem ser 100% match (não faz sentido "80% de array")

### **2. Reference Mode Needs Careful Path Tracking**
- Paths precisam incluir "root." para serem únicos
- `$ref:` precisa apontar para path completo, não só key

### **3. Empty Objects são Duplicatas Válidas**
- Inicialmente retornava `None` para empty objects
- Corrigido para `return out` (empty é valor legítimo)

### **4. removed_count Deve Incrementar em Ambos os Modes**
- Bug inicial: só incrementava em mode='remove'
- Reference mode também "remove" (substitui), então deve contar

### **5. Testes Rápidos são Essenciais**
- 19 tests em 0.21s → feedback instantâneo
- Pytest sem GUI é muito mais rápido que testes de integração
