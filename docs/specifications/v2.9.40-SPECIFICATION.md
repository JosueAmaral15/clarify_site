## 3. Architecture Decision

### 3.1 Design Pattern: Factory Method + Strategy

**Pattern Rationale**:
- **Factory Method**: `_show_*()` methods act as factories, creating tool widgets on-demand
- **Strategy**: `_add_tool_tab()` encapsulates tab addition logic, allowing different behaviors (duplicate prevention, persistence)
- **Lazy Loading**: Widgets created once and kept in memory (data preservation)

### 3.2 Before vs After

#### Before (QDockWidget approach):
```python
def _show_translate(self):
    if not hasattr(self, 'dock_translate'):
        self._open_trans()  # Creates JsonTranslateDock
    self.dock_translate.show()  # Shows dock in RightDockWidgetArea
```

**Issues**:
- `addDockWidget(Qt.RightDockWidgetArea, dock)` fills entire right side
- No close button on dock
- No state persistence
- No duplicate prevention

#### After (QTabWidget integration):
```python
def _show_translate(self):
    """Show JSON Translate as tab (create on-demand)."""
    if not hasattr(self, 'dock_translate'):
        from .gui import JsonTranslateDock
        self.dock_translate = JsonTranslateDock(self)
    self._add_tool_tab(self.dock_translate, "JSON Translate", "translate")
```

**Benefits**:
- Tab in central widget (no full-width occupation)
- Close button with theme styling
- State persisted via QSettings
- Duplicate prevention via `tool_tabs` dict

### 3.3 Data Flow

```
User clicks Tools > JSON Translate
    ↓
MainWindow._show_translate() called
    ↓
Check: hasattr(self, 'dock_translate')?
    ↓ YES → Use existing widget (data preserved)
    ↓ NO  → Create new JsonTranslateDock
    ↓
_add_tool_tab(widget, title, tool_name)
    ↓
Check: tool_name in self.tool_tabs?
    ↓ YES → Switch to existing tab (prevent duplicate)
    ↓ NO  → Add new tab + save to tool_tabs dict
    ↓
_save_tab_state() → Save to QSettings
```

## 4. Implementation Details

### 4.1 Tab Management System (4 core methods)

#### Method 1: `_add_tool_tab(widget, title, tool_name)`

**Purpose**: Add tool as tab, prevent duplicates, save state

**Logic**:
```python
def _add_tool_tab(self, widget: QWidget, title: str, tool_name: str) -> int:
    # 1. Check for existing tab
    if tool_name in self.tool_tabs:
        existing_widget, existing_index = self.tool_tabs[tool_name]
        self.tabs.setCurrentIndex(existing_index)  # Switch to existing
        return existing_index
    
    # 2. Add new tab
    tab_index = self.tabs.addTab(widget, title)
    
    # 3. Track in dict
    self.tool_tabs[tool_name] = (widget, tab_index)
    
    # 4. Activate and save
    self.tabs.setCurrentIndex(tab_index)
    self._save_tab_state()
    
    return tab_index
```

**Parameters**:
- `widget`: QWidget instance (tool dock widget)
- `title`: Tab display name (ex: "JSON Translate")
- `tool_name`: Unique identifier (ex: "translate")

**Returns**: Tab index (int)

#### Method 2: `_close_tab(index)`

**Purpose**: Close tab with confirmations for fixed tabs and unsaved data

**Logic**:
```python
def _close_tab(self, index: int):
    widget = self.tabs.widget(index)
    tab_title = self.tabs.tabText(index)
    
    # 1. Check if fixed tab (Search/Replace or Insert)
    if index < 2:
        reply = QMessageBox.question(
            self, "Close Fixed Tab",
            f"Are you sure you want to close '{tab_title}'?",
            QMessageBox.Yes | QMessageBox.No
        )
        if reply == QMessageBox.No:
            return
    
    # 2. Check for unsaved changes (only Editor has this method)
    if hasattr(widget, 'has_unsaved_changes') and callable(widget.has_unsaved_changes):
        if widget.has_unsaved_changes():
            reply = QMessageBox.question(
                self, "Unsaved Changes",
                f"'{tab_title}' has unsaved changes. Save before closing?",
                QMessageBox.Save | QMessageBox.Discard | QMessageBox.Cancel
            )
            if reply == QMessageBox.Cancel:
                return
            elif reply == QMessageBox.Save:
                widget.save_file()
    
    # 3. Remove tab
    self.tabs.removeTab(index)
    
    # 4. Update tracking dict (adjust indices for tabs after removed one)
    tool_to_remove = None
    for tool_name, (w, idx) in self.tool_tabs.items():
        if w == widget:
            tool_to_remove = tool_name
        elif idx > index:
            self.tool_tabs[tool_name] = (w, idx - 1)
    
    if tool_to_remove:
        del self.tool_tabs[tool_to_remove]
    
    # 5. Save state
    self._save_tab_state()
```

**Parameters**:
- `index`: Tab index to close (int, 0-based)

**Side Effects**:
- May show QMessageBox (confirmation dialogs)
- Modifies `self.tool_tabs` dict
- Saves state to QSettings

#### Method 3: `_apply_tab_close_button_style()`

**Purpose**: Apply theme-aware colors to close buttons

**Logic**:
```python
def _apply_tab_close_button_style(self):
    # 1. Get current theme
    current_theme = self.settings.get("theme", "system")
    
    # 2. Choose colors
    if current_theme == "dark":
        close_btn_color = "#B0B0B0"  # Light gray
        close_btn_hover = "#FFFFFF"  # White
    else:
        close_btn_color = "#505050"  # Dark gray
        close_btn_hover = "#000000"  # Black
    
    # 3. Apply QSS
    tab_style = f"""
        QTabWidget::close-button {{
            background: {close_btn_color};
            border-radius: 2px;
            width: 16px; height: 16px;
        }}
        QTabWidget::close-button:hover {{
            background: {close_btn_hover};
        }}
    """
    self.tabs.setStyleSheet(tab_style)
```

**Parameters**: None

**Called From**:
- `__init__()` (after `_build_ui()`)
- Theme change handler (when user switches theme)

#### Method 4: `_save_tab_state()` + `_restore_tab_state()`

**Purpose**: Persist and restore tab state across sessions

**Save Logic**:
```python
def _save_tab_state(self):
    # 1. Extract tool names from tracking dict
    open_tools = [tool_name for tool_name in self.tool_tabs.keys()]
    
    # 2. Save to QSettings
    self.settings.set("tabs_open_tools", open_tools)
    self.settings.set("tabs_current_index", self.tabs.currentIndex())
```

**Restore Logic**:
```python
def _restore_tab_state(self):
    # 1. Load from QSettings
    open_tools = self.settings.get("tabs_open_tools", [])
    if not open_tools:
        return
    
    # 2. Reopen each tool
    for tool_name in open_tools:
        method_name = f"_show_{tool_name}"
        if hasattr(self, method_name):
            method = getattr(self, method_name)
            method()  # Calls _show_translate(), etc.
    
    # 3. Restore active tab
    saved_index = self.settings.get("tabs_current_index", 0)
    if isinstance(saved_index, int) and saved_index < self.tabs.count():
        self.tabs.setCurrentIndex(saved_index)
```

**QSettings Schema**:
- **Key**: `tabs_open_tools`
  - **Type**: `list[str]`
  - **Example**: `["translate", "rewriter", "editor"]`
- **Key**: `tabs_current_index`
  - **Type**: `int`
  - **Example**: `2` (third tab active)

### 4.3 Unsaved Changes Detection (EditorDock)

#### Method: `has_unsaved_changes()`

**Purpose**: Check if any editor tab has unsaved modifications

**Logic**:
```python
def has_unsaved_changes(self) -> bool:
    """Check if any tab has unsaved changes (v2.9.40)."""
    for i in range(self.tab_widget.count()):
        tab = self.tab_widget.widget(i)
        
        # Check if tab is modified
        if hasattr(tab, 'modified') and tab.modified:
            # Only consider real unsaved changes (file-backed tabs)
            if hasattr(tab, 'file_path') and tab.file_path:
                return True
    
    return False
```

**Detection Criteria**:
1. Tab must have `modified=True` flag (content changed since last save)
2. Tab must have `file_path` attribute (exclude unsaved scratch tabs)

**Integration**:
- Called by `MainWindow._close_tab()` when closing Editor tab
- If returns `True`, shows Save/Discard/Cancel dialog

### 10.2 Known Limitations

- **Issue**: `index < 2` check assumes Search/Replace and Insert are always first
- **Risk**: If tab order changes, confirmation logic breaks
- **Fix**: Track fixed tabs by widget instance, not index

**2. QSettings and SettingsManager Duplication**
- **Issue**: Two persistence systems (QSettings for tabs, JSON for app settings)
- **Risk**: Inconsistent data storage
- **Fix**: Migrate AccessibilityManager to use SettingsManager

**3. No Error Handling for Invalid tool_name**
- **Issue**: `_restore_tab_state()` assumes all tool_name have corresponding `_show_*()` methods
- **Risk**: Missing method causes silent failure
- **Fix**: Add try/except around `getattr(self, method_name)`

## 12. Appendix: Code Snippets

### A.1 Complete _add_tool_tab() Method

```python
def _add_tool_tab(self, widget: QWidget, title: str, tool_name: str) -> int:
    """
    Add a tool as a tab in the central QTabWidget (v2.9.40).
    
    Args:
        widget: Tool widget instance (e.g., JsonTranslateDock)
        title: Display name for tab (e.g., "JSON Translate")
        tool_name: Unique identifier (e.g., "translate")
    
    Returns:
        int: Tab index where tool was added
    
    Behavior:
        - If tool already open, switches to existing tab (no duplicate)
        - Otherwise, adds new tab and saves state
    """
    # Check if tool is already open
    if tool_name in self.tool_tabs:
        existing_widget, existing_index = self.tool_tabs[tool_name]
        self.tabs.setCurrentIndex(existing_index)
        return existing_index
    
    # Add new tab
    tab_index = self.tabs.addTab(widget, title)
    
    # Track in dict
    self.tool_tabs[tool_name] = (widget, tab_index)
    
    # Switch to new tab
    self.tabs.setCurrentIndex(tab_index)
    
    # Save tab state to QSettings
    self._save_tab_state()
    
    return tab_index
```

### A.2 Complete _close_tab() Method

```python
def _close_tab(self, index: int):
    """
    Close a tab with confirmations for fixed tabs and unsaved data (v2.9.40).
    
    Args:
        index: Tab index to close (0-based)
    
    Confirmations:
        - Fixed tabs (Search/Replace, Insert): "Are you sure?" dialog
        - Editor with unsaved changes: "Save/Discard/Cancel" dialog
        - Other tools: Close without confirmation (data preserved)
    """
    widget = self.tabs.widget(index)
    tab_title = self.tabs.tabText(index)
    
    # Check if it's a fixed tab (Search/Replace or Insert)
    if index < 2:
        reply = QMessageBox.question(
            self,
            "Close Fixed Tab",
            f"Are you sure you want to close '{tab_title}'?\n"
            f"You can reopen it from the Tools menu.",
            QMessageBox.Yes | QMessageBox.No,
            QMessageBox.No
        )
        if reply == QMessageBox.No:
            return
    
    # Check for unsaved changes (only Editor has this method)
    if hasattr(widget, 'has_unsaved_changes') and callable(widget.has_unsaved_changes):
        if widget.has_unsaved_changes():
            reply = QMessageBox.question(
                self,
                "Unsaved Changes",
                f"'{tab_title}' has unsaved changes.\n"
                f"Do you want to save before closing?",
                QMessageBox.Save | QMessageBox.Discard | QMessageBox.Cancel,
                QMessageBox.Cancel
            )
            
            if reply == QMessageBox.Cancel:
                return
            elif reply == QMessageBox.Save:
                if hasattr(widget, 'save_file'):
                    widget.save_file()
    
    # Remove tab from QTabWidget
    self.tabs.removeTab(index)
    
    # Update tracking dict
    tool_to_remove = None
    for tool_name, (w, idx) in self.tool_tabs.items():
        if w == widget:
            tool_to_remove = tool_name
        elif idx > index:
            # Adjust indices for tabs after removed one
            self.tool_tabs[tool_name] = (w, idx - 1)
    
    if tool_to_remove:
        del self.tool_tabs[tool_to_remove]
    
    # Save tab state to QSettings
    self._save_tab_state()
```
