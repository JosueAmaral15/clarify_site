### Arquitetura

```

```

### Padrões Aplicados

1. **Composite (GoF)**
   - Panels reutilizáveis como componentes
   - Podem ser adicionados em qualquer QWidget
   - Interface uniforme (signals)

2. **Observer (GoF)**
   - Panels emitem signals
   - Docks conectam slots handlers
   - Low coupling

3. **Command (GoF)**
   - Operações encapsuladas (replace, insert)
   - Fácil undo/redo futuro

4. **Facade (GoF)**
   - Panels simplificam API core
   - Esconde complexidade regex/modes

## 🔧 Implementação Detalhada

### 1. SearchReplacePanel (280 LOC)

**Features**:
- ✅ Case sensitivity toggle
- ✅ Whole word matching
- ✅ Regex support
- ✅ Preserve case (ALL CAPS, Capitalized, lower)
- ✅ Replace count (0 = all)
- ✅ Test Pattern button (valida regex)
- ✅ QSettings persistence

**Signal**:
```python
replace_requested = Signal(str, str, SearchOptions, bool, int)
# Parameters: needle, replacement, options, preserve_case, count
```

**Usage**:
```python
panel = SearchReplacePanel(self, "my_prefix")
panel.replace_requested.connect(self._handle_replace)
layout.addWidget(panel)
```

**Core Integration**:
```python
from src.core.search_replace import compile, replace_in_text

pattern = compile(needle, options)
new_content, num = replace_in_text(content, pattern, repl, preserve_case, count)
```

### 2. InsertPanel (220 LOC)

**Features**:
- ✅ Line number selection (1-based)
- ✅ Multi-line text input
- ✅ 5 insertion modes (LEFT, RIGHT, REPLACE, INSERT_ABOVE, INSERT_BELOW)
- ✅ Quick mode buttons (← Left, Right →, 🔄 Replace)
- ✅ Preview button (mostra sample)
- ✅ QSettings persistence

**Signal**:
```python
insert_requested = Signal(int, str, str)
# Parameters: line_no, text, mode
```

**Usage**:
```python
panel = InsertPanel(self, "my_prefix")
panel.insert_requested.connect(self._handle_insert)
layout.addWidget(panel)
```

**Core Integration**:
```python
from src.core.insert import insert_at_line

new_content = insert_at_line(content, line_no, text, mode)
```

### 3. AI Processor Integration (+85 LOC)

**Localização**: Após stats_group, antes de results panel

**SearchReplacePanel**:
- Conectado a `_handle_replace_in_results()`
- Processa `self.text_results.toPlainText()`
- Atualiza `self.text_results.setPlainText(new_content)`
- Mostra feedback com num_replaced

**InsertPanel**:
- Conectado a `_handle_insert_in_prompt()`
- Processa `self.ed_prompt.toPlainText()`
- Atualiza `self.ed_prompt.setPlainText(new_content)`
- Mostra feedback com mode usado

**Error Handling**:
```python
try:
    pattern = compile(needle, options)
    new_content, num = replace_in_text(...)
    self.show_message("Replace Complete", f"{num} occurrences")
except Exception as e:
    self.show_error("Replace Error", str(e))
```

### 4. JSON Editor Integration (+60 LOC)

**Localização**: Abaixo da toolbar, acima do splitter

**Button**: `📝 Insert` na toolbar
- Toggle visibility do InsertPanel
- Seta line number para cursor position atual

**InsertPanel**:
- Conectado a `_handle_insert()`
- Processa `self.editor.toPlainText()`
- Atualiza `self.editor.setPlainText(new_content)`
- Marca `_on_text_changed()` (modified flag)
- Auto-hide após inserção

**Toggle Logic**:
```python
def _toggle_insert_panel(self):
    if self.insert_panel.isVisible():
        self.insert_panel.setVisible(False)
        self.btn_insert_panel.setText("📝 Insert")
    else:
        self.insert_panel.setVisible(True)
        self.btn_insert_panel.setText("✕ Close Insert")
        cursor_line = self.editor.textCursor().blockNumber() + 1
        self.insert_panel.set_line_number(cursor_line)
```

## 📚 Documentação para Desenvolvedores

### Criando Novo Panel Reutilizável

```python
# 1. Herdar de QWidget
from PySide6.QtWidgets import QWidget
from PySide6.QtCore import Signal, QSettings

class MyPanel(QWidget):
    # 2. Definir signal
    action_requested = Signal(str, int)  # params customizáveis
    
    def __init__(self, parent=None, settings_prefix="my_panel"):
        super().__init__(parent)
        self.settings_prefix = settings_prefix
        self.settings = QSettings("Clarify", "Clarify")
        self._setup_ui()
        self._load_settings()
    
    def _setup_ui(self):
        # 3. Criar widgets
        layout = QVBoxLayout(self)
        group = QGroupBox("My Panel")
        # ... adicionar widgets
        layout.addWidget(group)
    
    def _execute_action(self):
        # 4. Emitir signal
        self._save_settings()
        self.action_requested.emit(param1, param2)
    
    def _save_settings(self):
        # 5. Persistir estado
        self.settings.setValue(f"{self.settings_prefix}/param", value)
```

### Integrando Panel em Dock

```python
from src.gui.panels import MyPanel

class MyDock(StandardToolDock):
    def _setup_ui(self):
        # ... UI existente ...
        
        # Adicionar panel
        self.my_panel = MyPanel(self, "my_dock_panel")
        self.my_panel.action_requested.connect(self._handle_action)
        self.layout.addWidget(self.my_panel)
    
    def _handle_action(self, param1, param2):
        """Handle panel action."""
        try:
            # Processar ação
            result = do_something(param1, param2)
            self.show_message("Success", f"Result: {result}")
        except Exception as e:
            self.show_error("Error", str(e))
```
