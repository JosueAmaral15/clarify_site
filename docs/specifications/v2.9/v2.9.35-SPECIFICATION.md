## 📦 Features Implemented

### 1. AccessibilityManager API

**File**: `src/accessibility_manager.py` (330 LOC)

#### Core Methods

```python
@staticmethod
def set_accessible_widget(widget: QWidget, name: str, description: Optional[str] = None):
    """Set accessible name and description for screen readers."""
    widget.setAccessibleName(name)
    if description:
        widget.setAccessibleDescription(description)
```

**Usage Example**:
```python
from src.accessibility_manager import AccessibilityManager

button = QPushButton("Run")
AccessibilityManager.set_accessible_widget(
    button,
    "Run JSON Rewriter",
    "Execute JSON rewrite operation on selected file"
)
```

#### Focus Indicators

```python
@staticmethod
def apply_focus_indicators(app: QApplication):
    """Apply global focus indicators via QSS."""
    focus_qss = """
    *:focus { border: 2px solid #007ACC; outline: none; }
    QPushButton:focus { border: 2px solid #007ACC; }
    QLineEdit:focus { border: 2px solid #007ACC; }
    /* ... more widgets ... */
    """
    app.setStyleSheet(current_stylesheet + "\n" + focus_qss)
```

**Result**: All focusable widgets get visible 2px blue border when focused (Tab key navigation).

#### Font Scaling

```python
# Increase font by 1pt
AccessibilityManager.increase_font_size(app, settings)

# Decrease font by 1pt  
AccessibilityManager.decrease_font_size(app, settings)

# Reset to default (10pt)
AccessibilityManager.reset_font_size(app, settings)
```

**Keyboard Shortcuts** (integrated in `MainWindow`):
- **Ctrl+Scroll Up**: Increase font size
- **Ctrl+Scroll Down**: Decrease font size
- **Ctrl+0**: Reset to default

**Range**: 8pt (min) to 24pt (max)  
**Persistence**: Saved to `~/.config/Clarify/clarify.ini` under `[accessibility]/font_size`

#### WCAG Contrast Ratio Calculator

```python
ratio = AccessibilityManager.get_contrast_ratio(30, 30, 30, 240, 240, 240)
# Returns: 14.628 (dark theme, exceeds WCAG AAA 7:1)

ratio = AccessibilityManager.get_contrast_ratio(250, 250, 250, 30, 30, 30)
# Returns: 15.972 (light theme, exceeds WCAG AAA 7:1)
```

**WCAG Standards**:
- AA Normal Text: ≥4.5:1
- AA Large Text: ≥3:1  
- AAA Normal Text: ≥7:1
- AAA Large Text: ≥4.5:1

**Clarify Compliance**: ✅ **Exceeds WCAG AAA** (14.6:1 dark, 16:1 light)

#### Tab Order API

```python
AccessibilityManager.configure_tab_order([
    input_field,
    browse_button,
    run_button
])
```

**Purpose**: Ensures logical keyboard navigation order (Tab key cycles widgets in specified order).

#### Screen Reader Support

```python
AccessibilityManager.enable_screen_reader_support(app)
```

**Platform Support**:
- Linux: Orca (AT-SPI)
- Windows: NVDA, JAWS (MSAA/UIA)
- macOS: VoiceOver (Accessibility API)

**Note**: Qt automatically enables accessibility when screen reader is detected. This method explicitly enables it.

### 2. MainWindow Integration

**File**: `src/app.py` (modified)

#### Startup Integration

```python
def __init__(self, app: QApplication):
    # ... existing initialization ...
    self._apply_accessibility()  # NEW: Apply accessibility features
```

#### Apply Accessibility Method

```python
def _apply_accessibility(self):
    """Apply accessibility features (v2.9.35)."""
    from .accessibility_manager import AccessibilityManager
    
    # Apply focus indicators globally
    AccessibilityManager.apply_focus_indicators(QApplication.instance())
    
    # Enable screen reader support
    AccessibilityManager.enable_screen_reader_support(QApplication.instance())
    
    # Load and apply saved font size
    font_size = AccessibilityManager.get_font_size(self.settings.qsettings)
    AccessibilityManager.apply_font_size(QApplication.instance(), font_size)
```

#### Wheel Event (Font Scaling)

```python
def wheelEvent(self, event):
    """Handle mouse wheel for font scaling (v2.9.35)."""
    if event.modifiers() == Qt.ControlModifier:
        from .accessibility_manager import AccessibilityManager
        
        if event.angleDelta().y() > 0:
            new_size = AccessibilityManager.increase_font_size(
                QApplication.instance(), self.settings.qsettings
            )
            self.statusBar().showMessage(f"Font size: {new_size}pt", 2000)
        else:
            new_size = AccessibilityManager.decrease_font_size(
                QApplication.instance(), self.settings.qsettings
            )
            self.statusBar().showMessage(f"Font size: {new_size}pt", 2000)
        
        event.accept()
```

#### Key Press Event (Ctrl+0 Reset)

```python
def keyPressEvent(self, event):
    """Handle global keyboard shortcuts (v2.9.33 + v2.9.35)."""
    # ... existing shortcuts ...
    
    # Ctrl+0 - Reset font size (v2.9.35)
    elif key == Qt.Key_0 and modifiers == Qt.ControlModifier:
        self._reset_font_size()
        event.accept()
        return
```

## 🚀 Usage Guide

### For End Users

**1. Adjust Font Size**:
- Hold **Ctrl** and scroll mouse wheel up/down
- Status bar shows current font size
- Press **Ctrl+0** to reset to default

**2. Keyboard Navigation**:
- Press **Tab** to move between widgets
- Focused widget shows blue border (2px)
- Use arrow keys within lists/comboboxes

**3. Screen Reader (Orca on Linux)**:
```bash
# Start Orca
orca --enable-speech

# Launch Clarify
python -m clarify

# Navigate with Tab, Orca will read accessible names
```

### For Developers

**1. Add Accessible Names to New Widgets**:
```python
from src.accessibility_manager import AccessibilityManager

# Create widget
button = QPushButton("Run")

# Set accessible name (required for screen readers)
AccessibilityManager.set_accessible_widget(
    button,
    "Run Button",  # Short name
    "Execute the JSON rewrite operation"  # Detailed description
)
```

**2. Configure Tab Order in Docks**:
```python
def _create_layout(self):
    # ... create widgets ...
    
    # Set logical tab order
    AccessibilityManager.configure_tab_order([
        self.ed_input_path,
        self.btn_browse_input,
        self.ed_output_path,
        self.btn_browse_output,
        self.btn_run
    ])
```

**3. Check Contrast Ratio for New Colors**:
```python
from src.accessibility_manager import AccessibilityManager

# Test new color scheme
bg_color = (20, 20, 20)  # RGB
text_color = (230, 230, 230)  # RGB

ratio = AccessibilityManager.get_contrast_ratio(
    bg_color[0], bg_color[1], bg_color[2],
    text_color[0], text_color[1], text_color[2]
)

print(f"Contrast ratio: {ratio:.2f}:1")
# Must be ≥4.5:1 for WCAG AA, ≥7:1 for WCAG AAA
```

## 🔄 Rollback Plans

### Scenario 1: Font Scaling Causes UI Issues

**Symptoms**: UI becomes unusable at certain font sizes

**Rollback**:
1. Delete font size setting:
   ```bash
   # Linux
   rm ~/.config/Clarify/clarify.ini
   # App will regenerate with default 10pt
   ```

2. Or manually edit INI:
   ```bash
   nano ~/.config/Clarify/clarify.ini
   # Change [accessibility] font_size=10
   ```

### Scenario 2: Focus Indicators Conflict with Theme

**Symptoms**: Blue borders clash with dark theme or are invisible

**Hotfix**:
1. Edit `src/accessibility_manager.py`:
   ```python
   # Change focus color from #007ACC to theme-aware color
   # Dark theme: #00AAFF (brighter blue)
   # Light theme: #0066CC (darker blue)
   ```

2. Rebuild and restart app

### Scenario 3: Screen Reader Causes Crashes

**Symptoms**: App crashes when Orca is running

**Rollback**:
1. Comment out screen reader enablement:
   ```python
   # In src/app.py _apply_accessibility():
   # AccessibilityManager.enable_screen_reader_support(QApplication.instance())
   ```

2. Restart app

### Scenario 4: Complete Rollback

**Revert all accessibility features**:
```bash
git revert v2.9.35
git push
```
