### Task #39: Quick Filter - File List Table
**Complexidade**: 🟢 Baixa (15min)  
**Categoria**: Usability  
**Status**: ✅ Completo

Adiciona textbox de filtro rápido acima da tabela do File List, permitindo filtrar resultados por filename em tempo real sem re-executar a busca.

#### Funcionalidades
- **Input**: QLineEdit com placeholder "Quick filter by filename..."
- **Behavior**: Filtra linhas da tabela em tempo real (textChanged signal)
- **Search**: Case-insensitive substring match
- **Performance**: Instant (sem I/O, apenas hide/show rows)

#### Exemplo de Uso
```
Tabela com 1000 arquivos listados
Digite "config" no filtro → mostra apenas 15 arquivos
Digite "config.json" → mostra apenas 3 arquivos
Limpe o filtro → mostra todos 1000 novamente
```

#### Implementação Técnica
```python
# src/gui/file_list_dock.py

# Widget creation (~linha 68)
self.ed_quick_filter = QLineEdit()
self.ed_quick_filter.setPlaceholderText("Quick filter by filename...")
self.ed_quick_filter.textChanged.connect(self._apply_quick_filter)

# Layout placement (~linha 119)
layout.addWidget(self.ed_quick_filter)

# Filter method (~linha 147)
def _apply_quick_filter(self, text: str):
    """Apply quick filter to visible rows."""
    text = text.lower()
    for row in range(self.table.rowCount()):
        name_item = self.table.item(row, 0)
        if name_item:
            name = name_item.text().lower()
            self.table.setRowHidden(row, text not in name)
```

**12 linhas adicionadas** | **Tempo: 15min**
