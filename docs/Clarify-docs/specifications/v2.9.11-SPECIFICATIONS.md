### Task #35: Skip Keys Without Siblings
**Complexidade**: 🟢 Baixa (30min)  
**Categoria**: JSON Rewriter  
**Status**: ✅ Completo

Remove hierarquias seriais (cadeias) onde chaves não possuem siblings, simplificando estruturas JSON desnecessariamente aninhadas.

#### Exemplos

**Entrada (Cadeia Serial)**:
```json
{
  "a": {
    "b": {
      "c": "valor"
    }
  }
}
```
**Saída**: `{}` (toda cadeia removida, nenhum sibling)

**Entrada (Com Siblings)**:
```json
{
  "a": {
    "b": "v1",
    "c": "v2"
  }
}
```
**Saída**: Mantido (b e c são siblings)

#### Implementação Técnica
- **Arquivo**: `src/rewriter/operations.py`
  - Função: `skip_keys_without_siblings(node: JSONNode) -> JSONNode`
  - Algoritmo bottom-up recursivo:
    1. Processa children primeiro (depth-first)
    2. Conta children após remoção recursiva
    3. Remove parent se len(children) == 1 (cadeia serial)
    4. Helper: `has_siblings_in_subtree()` verifica múltiplos filhos
- **Integração GUI**: `src/gui/json_rewriter_dock.py`
  - Checkbox: "Skip keys without siblings"
  - Layout: Row 4 (Array operations section)
  - Namespace parameter: `skip_no_siblings`
- **Testes**: `tests/test_skip_no_siblings.py`
  - 7 cenários: cadeia serial, com siblings, misto, nested chains, vazio, top-level, single-with-nested

### Task #33: File List with ls/dir Parameters
**Complexidade**: 🟢 Baixa (45min)  
**Categoria**: Utilities  
**Status**: ✅ Completo

Dock panel para listagem de arquivos com parâmetros Unix-like (ls/dir).

#### Funcionalidades
1. **Parâmetros**:
   - `-a`: Show hidden files (dotfiles)
   - `-l`: Long format (detailed info)
   - `-h`: Human-readable sizes (KB, MB, GB)
   - `-R`: Recursive (subdirectories)

2. **Output Table**:
   - Colunas: Name | Size | Modified | Permissions | Path
   - Permissions: Unix-style (`drwxr-xr-x`)
   - Long format: inclui `owner:group`
   - Sortable por qualquer coluna

3. **Features Extras**:
   - Stats: item count + total size
   - Export to CSV
   - Directory browser

#### Implementação Técnica
- **Arquivo**: `src/gui/file_list_dock.py` (novo dock)
  - Classe: `FileListDock(BaseDock)`
  - Helpers:
    * `_collect_files()`: recursivo com hidden filter
    * `_format_permissions()`: stat.S_IRUSR → `drwxr-xr-x`
    * `_get_owner()` / `_get_group()`: pwd/grp lookup
    * `_human_readable_size()`: bytes → KB/MB/GB
- **Integração**:
  - `src/gui/__init__.py`: exporta `FileListDock`
  - `src/app.py`: menu Tools → File List...
  - Inicialização: `_open_file_list()` chamado no startup
