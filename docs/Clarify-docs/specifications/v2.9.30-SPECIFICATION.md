## Overview

**Sprint B Feature #4** extends the Reference Resolver (v2.9.29) with:

1. **Multi-Format Support**: 3 reference formats ($ref:, #/, @) instead of just $ref:
2. **Format Configuration UI**: Dialog to choose format style, line numbers, and relative paths
3. **Relative Path Support**: Option to remove 'root.' prefix from paths
4. **QSettings Persistence**: User preferences saved and restored between sessions

This feature enables users to customize how duplicate objects are replaced with references, supporting different reference notation styles commonly used in JSON Schema, JSON Pointer (RFC 6901), and compact custom formats.

## Backend Implementation

### File: `src/rewriter/reference_resolver.py`

#### New Function: `format_reference()`

```python
def format_reference(
    path: str,
    line: Optional[int] = None,
    format_type: str = '$ref',
    use_relative_path: bool = False
) -> str:
```

**Purpose**: Format a reference string in the specified style.

**Parameters**:
- `path`: Dot-notation path (e.g., 'root.users.admin')
- `line`: Optional line number
- `format_type`: Format style ('$ref', '#/', or '@')
- `use_relative_path`: If True, remove 'root.' prefix

**Formats**:
1. **$ref: (Default)** - Fully resolvable, explicit prefix
   - `$ref:root.users.admin:123`
   - `$ref:users.admin` (relative)

2. **#/ (JSON Pointer RFC 6901)** - Standard JSON Pointer notation
   - `#/root.users.admin:456`
   - `#/users.admin` (relative)

3. **@ (Compact)** - Custom shorthand format
   - `@root.users.admin:789`
   - `@users.admin` (relative)

**Algorithm**:
```python
# 1. Remove 'root.' prefix if relative
if use_relative_path and path.startswith('root.'):
    path = path[5:]

# 2. Format based on type
if format_type == '$ref': base = f'$ref:{path}'
elif format_type == '#/': base = f'#/{path}'
elif format_type == '@': base = f'@{path}'
else: base = f'$ref:{path}'  # Fallback

# 3. Append line number if provided
if line is not None and line > 0:
    return f'{base}:{line}'
return base
```

**Examples**:
```python
format_reference('root.users.admin', 123, '$ref', False)  
# → '$ref:root.users.admin:123'

format_reference('root.users.admin', None, '#/', True)
# → '#/users.admin'

format_reference('root.users.admin', 456, '@', True)
# → '@users.admin:456'
```

#### Updated Function: `resolve_references()`

```python
def resolve_references(
    node: JSONNode
) -> Tuple[JSONNode, Dict[str, int]]:
```

**Changes**:
- Multi-format detection: Checks for `$ref:`, `#/`, or `@` prefixes
- Unified regex: `r'^(?:\$ref:|#/|@)([^:]+)(?::(\d+))?$'`
- Relative path resolution: Tries both exact path and with 'root.' prefix

**Algorithm**:
```python
# 1. Check if string starts with any reference prefix
if isinstance(n, str) and (n.startswith('$ref:') or n.startswith('#/') or n.startswith('@')):
    
    # 2. Parse with multi-format regex
    ref_pattern = r'^(?:\$ref:|#/|@)([^:]+)(?::(\d+))?$'
    match = re.match(ref_pattern, n)
    
    if not match:
        # Invalid format
        print(f"⚠️  Warning: Invalid reference format '{n}' at {path}")
        stats['invalid'] += 1
        return n
    
    ref_path = match.group(1)     # path.to.key
    ref_line = match.group(2)     # optional line number
    
    # 3. Try to resolve
    resolved_value = None
    
    # Try exact path first
    if ref_path in index:
        resolved_value = index[ref_path]
    
    # If not found and path doesn't start with 'root.', try adding it (relative path)
    elif not ref_path.startswith('root.'):
        absolute_path = f'root.{ref_path}'
        if absolute_path in index:
            resolved_value = index[absolute_path]
    
    # 4. Return resolved value or keep as-is with warning
    if resolved_value is not None:
        stats['resolved'] += 1
        return resolved_value
    else:
        print(f"⚠️  Warning: Reference target not found: '{ref_path}' (line {ref_line}) at {path}")
        stats['invalid'] += 1
        return n
```

**Supported Formats** (all with optional `:line`):
- `$ref:root.users.admin:123` → Resolves to value at root.users.admin
- `#/root.users.admin` → Same lookup
- `@users.admin` → Tries 'users.admin', then 'root.users.admin' (relative)

## User Workflow

### Step 1: Enable Reference Mode

In JSON Rewriter Dock:
1. Select **"Use references ($ref)"** radio button
2. Process file as normal

**Output** (with default settings):
```json
{
  "user": {"name": "Alice", "role": "admin"},
  "author": "$ref:root.user:2",
  "admin": "$ref:root.user:2"
}
```

### Step 2: Configure Format (Optional)

1. Click **"⚙️ Configure Format..."** button
2. In dialog:
   - Choose format: `#/` (JSON Pointer)
   - ✓ Include line numbers
   - ✓ Use relative paths
3. Preview shows: `Example: #/users.admin:123`
4. Click **OK** to save

### Step 3: Process with New Format

Run rewrite again with same file:

**Output** (with #/ + relative):
```json
{
  "user": {"name": "Alice", "role": "admin"},
  "author": "#/user:2",
  "admin": "#/user:2"
}
```

### Step 4: Resolve References

1. Check **"Resolve existing references"**
2. Process file

**Output** (references expanded):
```json
{
  "user": {"name": "Alice", "role": "admin"},
  "author": {"name": "Alice", "role": "admin"},
  "admin": {"name": "Alice", "role": "admin"}
}
```

**Multi-format Resolution**: Works with all 3 formats ($ref:, #/, @) automatically!
