### 📊 ANTES

```json

  "message": "It\\\\'s a test",
  "quote": "She said \\\\\"hello\\\\\""
}
```

**Problemas**:
- ❌ Escaping excessivo de 3-4 backslashes
- ❌ Output ilegível: `It\\\\'s` em vez de `It\'s`
- ❌ Sem detecção automática

### 📊 DEPOIS

```python
# src/rewriter/operations.py
def normalize_escaping(node: JSONNode) -> JSONNode:
    """
    Normaliza escaping excessivo em strings JSON.
    Detecta \\\' ou mais → \'
    Detecta \\" ou mais → \"
    """
    if isinstance(node, str):
        # Regex para detectar 2+ backslashes antes de aspas
        node = re.sub(r'\\{2,}\'', r'\\\'', node)
        node = re.sub(r'\\{2,}"', r'\\"', node)
    elif isinstance(node, Obj):
        return Obj([(k, normalize_escaping(v)) for k, v in node.items()])
    return node
```

**Output Normalizado**:
```json
{
  "message": "It\\'s a test",
  "quote": "She said \\\"hello\\\""
}
```

**Melhorias**:
- ✅ Detecção automática via regex `\\{2,}`
- ✅ Preserva escaping válido (single backslash)
- ✅ Recursivo para objetos aninhados
- ✅ Checkbox no GUI para habilitar/desabilitar

### 🧪 Testes


### 📊 ANTES

```json
{
  "messages": [
    "O usuário pode seguir com as instruções",
    "Pesquisa alternativa",
    "Não é possível acessar esta página"
  ]
}
```

**Problemas**:
- ❌ Arrays difíceis de referenciar por índice
- ❌ Sem nomes semânticos para valores
- ❌ Não funciona com i18n: `t.messages[0]` vs `t.messages.userCanFollow`

### 📊 DEPOIS

```python
# src/rewriter/operations.py
def array_to_object_conversion(
    node: JSONNode,
    max_key_length: int = 30,
    case_style: str = 'camel',
    scope_path: str = ''
) -> JSONNode:
    """
    Converte arrays de strings para objetos com chaves geradas.
    
    Algoritmo:
    1. Extrai primeiros 30 chars do valor
    2. Remove acentos com unicodedata.normalize('NFD')
    3. Remove caracteres especiais (mantém apenas [a-zA-Z0-9])
    4. Converte para case style (camel/pascal/snake/kebab)
    5. Resolve conflitos adicionando mais palavras do valor
    """
```

**Output Convertido**:
```json
{
  "messages": {
    "oUsuarioPodeSeguirComAsInst": "O usuário pode seguir com as instruções",
    "pesquisaAlternativa": "Pesquisa alternativa",
    "naoEPossivelAcessarEstaPagin": "Não é possível acessar esta página"
  }
}
```

**Melhorias**:
- ✅ Geração automática de chaves a partir do conteúdo
- ✅ Remove acentos: "usuário" → "usuario"
- ✅ 4 case styles: camelCase, PascalCase, snake_case, kebab-case
- ✅ Resolução de conflitos sem sufixos numéricos
- ✅ Apenas converte arrays 100% strings (preserva mixed arrays)

### 🧪 Testes

