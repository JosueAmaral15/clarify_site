**Handler Method**:
```python
def _apply_theme_action(self, action: QAction) -> None:
    """
    Handles theme menu action clicks.
    
    Behavior:
        1. Unchecks all theme actions (radio behavior)
        2. Checks clicked action
        3. Extracts mode from action text
        4. Applies theme via ThemeManager
        5. Persists mode to QSettings
    """
    # Uncheck all
    for a in self.menuBar().findChild(QMenu, "themes").actions():
        a.setChecked(False)
    
    # Check selected
    action.setChecked(True)
    
    # Determine mode
    text = action.text().lower()
    if "system" in text or "sistema" in text:
        mode = "system"
    elif "light" in text or "claro" in text:
        mode = "light"
    elif "dark" in text or "escuro" in text:
        mode = "dark"
    
    # Apply theme
    apply_theme(QApplication.instance(), mode)
    
    # Persist to QSettings
    cfg = load_prefs()  # Returns dict from ~/.config/Clarify/clarify.ini
    cfg["THEME"]["mode"] = mode
    save_prefs(cfg)
```

#### Accessibility Test Details

**Contrast Ratio Calculation**:
```python
def calculate_contrast_ratio(color1: QColor, color2: QColor) -> float:
    """
    Calculates WCAG contrast ratio between two colors.
    Formula: (L1 + 0.05) / (L2 + 0.05) where L1 > L2
    L = relative luminance = 0.2126*R + 0.7152*G + 0.0722*B (sRGB)
    """
    def relative_luminance(color: QColor) -> float:
        r, g, b = color.red() / 255.0, color.green() / 255.0, color.blue() / 255.0
        # Apply gamma correction
        r = r / 12.92 if r <= 0.03928 else ((r + 0.055) / 1.055) ** 2.4
        g = g / 12.92 if g <= 0.03928 else ((g + 0.055) / 1.055) ** 2.4
        b = b / 12.92 if b <= 0.03928 else ((b + 0.055) / 1.055) ** 2.4
        return 0.2126 * r + 0.7152 * g + 0.0722 * b
    
    l1 = relative_luminance(color1)
    l2 = relative_luminance(color2)
    return (max(l1, l2) + 0.05) / (min(l1, l2) + 0.05)
```

## 🏗️ Design Decisions

### Why Inline QSS?

**Advantages**:
1. **Security**: No file I/O, prevents path traversal attacks (CWE-22)
2. **Distribution**: Single executable, no missing CSS files
3. **Performance**: No disk reads, faster theme application
4. **Maintainability**: Code and styles in same file, easier to review

**Disadvantages**:
1. **File Size**: Adds ~200 lines to `theme_manager.py`
2. **Reload**: Requires app restart to change styles (acceptable for themes)

**Decision**: Inline QSS chosen for security and simplicity.

### Why QPalette + QSS Combination?

**Reasoning**:
- QPalette: Affects native Qt widgets (QMessageBox, QFileDialog, system dialogs)
- QSS: Affects custom styled widgets (QTextEdit, QTableWidget)
- Combination ensures **100% coverage**

**Example**: QFileDialog uses QPalette (native), while main window uses QSS (custom).

### Why System Theme Detection?

**Qt 6.5+ Feature**:
```python
color_scheme = QGuiApplication.styleHints().colorScheme()
# Returns: Qt.ColorScheme.Dark or Qt.ColorScheme.Light
```

**Fallback for Qt 6.4 and below**:
```python
if not hasattr(QGuiApplication.styleHints(), 'colorScheme'):
    return "light"  # Default to light theme
```

**User Control**: Menu allows override ("Light" or "Dark" instead of "System")
