## 📋 Overview

Sistema de benchmarks de performance para operações críticas do Clarify, medindo tempo de execução, uso de memória RAM e CPU usage em arquivos JSON de diferentes tamanhos (1MB, 10MB, 50MB, 100MB).

### Problema Resolvido

**Antes**: Sem métricas objetivas de performance, impossível identificar regressões ou otimizar operações críticas.

**Depois**: 
- Benchmarks automatizados para operações core
- Métricas detalhadas (tempo, memória, CPU)
- Histórico de resultados para comparação entre versões
- Identificação de bottlenecks em operações lentas

## 🏗️ Architecture

### Operações Benchmarked

1. **Set Operations** (`src/set_operations.py`):
   - Union de 2 arquivos grandes
   - Intersection com comparação profunda
   - Difference com nested keys
   - Symmetric Difference

2. **JSON Rewriter** (`src/rewriter/json_rewriter.py`):
   - Deduplicate em arrays grandes (10k+ items)
   - Normalize structure (flatten/unflatten)
   - Remove empty values recursively

3. **JSON Search** (`src/json_search/`):
   - Search por chave em estrutura profunda (depth 20+)
   - Search por valor com regex
   - Busca em múltiplos arquivos

4. **Text Extractor** (`src/text_extractor/`):
   - Extrair texto de HTML grande (1MB+)
   - JSX parsing com 1000+ componentes

5. **TOON/BSON Converters** (`src/converters/`):
   - JSON → TOON (encoding)
   - TOON → JSON (decoding)
   - JSON → BSON → JSON (roundtrip)
