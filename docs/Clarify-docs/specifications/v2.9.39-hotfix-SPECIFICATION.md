## 2. Problem Statement

### 2.1 Technical Problems

#### Problem 1: Relative Imports Beyond Top-Level

**Affected Files** (9 locations):
1. `src/gui/json_translate_dock.py:31`
2. `src/gui/case_validator_dialog.py:9`
3. `src/gui/case_validator_dialog.py:10`
4. `src/gui/jsx_extractor_dock.py:429`
5. `src/gui/json_rewriter_dock.py:108`
6. `src/gui/json_rewriter_dock.py:765`
7. `src/gui/json_rewriter_dock.py:876`
8. `src/gui/set_operations_dock.py:299`

**Pattern**:
```python
# ❌ ERRADO (relative import além de top-level)
from ..utils import load_ts_object
from ..rewriter import rewrite_json_node
from .. import rewriter

# ✅ CORRETO (absolute import)
from src.utils import load_ts_object
from src.rewriter import rewrite_json_node
from src import rewriter
```

**Root Cause**: Uso incorreto de `..` em contexto onde módulo pai não existe na estrutura de pacotes Python.

#### Problem 2: Missing Individual Timeouts

**Current State** (v2.9.38):
```toml
# pyproject.toml
[tool.pytest.ini_options]
addopts = ["--timeout=30"]  # Global 30s para TODOS os testes
```

**Issues**:
- Unit tests (rápidos): 30s é excessivo, atrasa feedback
- Integration tests (lentos): 30s pode não ser suficiente
- Sem distinção clara de categorias

**User Requirement**:
> "Faça essas configurações com timeouts de forma individual, respeitando o limite máximo de 60 segundos"

#### Problem 3: Documentation Gaps

**Trailing Whitespace**: `settings_manager.py` (22 linhas)
```
C0303: Trailing whitespace (trailing-whitespace)
```

**Missing Docstrings** (11 funções):
- `set_operations_dock.py`: 9 funções públicas sem docstrings
- `case_validator_dialog.py`: 2 funções (`__init__`, `_update_preview`)

**Impact**: Reduz clareza, dificulta manutenção, gera warnings.

## 3. Solution Implemented

### 3.1 Import Correction Strategy

**Approach**: Systematic replacement usando padrão absoluto.

**Regras de Conversão**:

| Situação | Antes | Depois |
|----------|-------|--------|
| Cross-package | `from ..utils import X` | `from src.utils import X` |
| Core modules | `from .. import rewriter` | `from src import rewriter` |
| Same package | `from ..gui.base_dock` | `from .base_dock` |

**Execution**:
```bash
# Discovery
grep -rn "from \.\." src/gui/*.py

# Correction (manual via replace_string_in_file)
# 9 substituições realizadas
```

### 3.2 Timeout Configuration

**Implementação (Opção A - filename-based)**:

#### Default Timeout (unit tests)
```toml
# pyproject.toml
[tool.pytest.ini_options]
addopts = [
    "--timeout=10",  # 10s default
]
timeout_func_only = true  # Apenas funções, não setup/teardown

markers = [
    "integration: marks tests as integration tests (60s timeout)",
]
```

#### Integration Tests Timeout
```python
# tests/test_advanced_conditions_integration.py
import pytest

pytestmark = pytest.mark.timeout(60)  # TODOS os testes neste arquivo = 60s
```

**Pattern**: `*_integration.py` → 60s, outros → 10s.

#### CI/CD Configuration
```yaml
# .github/workflows/ci.yml
- name: Run tests with coverage
  run: |
    pytest --cov=src --cov-report=term-missing \
      --timeout=10 --cov-fail-under=70  # 70% gradual até 90%
```
