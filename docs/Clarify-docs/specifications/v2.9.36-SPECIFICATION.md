# Specification: v2.9.36 - Internationalization (i18n) Expansion

## Overview
**Release**: v2.9.36  
**Date**: December 2, 2025  
**Feature**: Internationalization (i18n) Expansion - 5 New Languages  
**Estimated Effort**: ~85 minutes (actual: ~90 minutes)  
**Protocol**: Simplicidade 3 v3.0 (16 steps)  

## Objective
Expand Clarify's internationalization support from 2 languages (EN, PT-BR) to 7 languages by adding Spanish, French, German, Chinese (Simplified), and Japanese translations, enabling users worldwide to interact with Clarify in their native language.

## Requirements

### Functional Requirements
1. **FR-001**: Create 5 new translation JSON files: `es.json`, `fr.json`, `de.json`, `zh.json`, `ja.json`
2. **FR-002**: Each file must contain all 240 translation keys (expanded from original 182)
3. **FR-003**: All files must be valid JSON with UTF-8 encoding
4. **FR-004**: CJK languages (Chinese, Japanese) must use proper Unicode characters
5. **FR-005**: All translations must be functional (no empty strings or placeholders)
6. **FR-006**: Each file must include metadata: `_comment` and `_translators` fields

### Non-Functional Requirements
1. **NFR-001**: File size ~7KB each (193 lines average)
2. **NFR-002**: 100% test coverage for new files (14 tests minimum)
3. **NFR-003**: No external dependencies (pure JSON)
4. **NFR-004**: Translation quality baseline (community can improve)
5. **NFR-005**: Consistent key structure across all 7 languages

## Technical Design

### Translation Key Categories
1. **app.*** (2 keys): Application title and version
2. **menu.*** (33 keys): Menu items (File, Edit, Tools, View, etc.)
3. **search.*** (17 keys): Search interface (path, query, buttons, options)
4. **tooltip.*** (21 keys): Tooltips for UI elements
5. **context.*** (5 keys): Context menu items
6. **status.*** (5 keys): Status messages (completed, failed, paused, etc.)
7. **dialog.*** (9 keys): Dialog UI elements (OK, Cancel, preferences, etc.)
8. **error.*** (4 keys): Error messages (file not found, invalid path, etc.)
9. **shortcuts.*** (144 keys): Keyboard shortcuts (categories, actions, descriptions, dialog)

### Translation Metadata Format
```json
{
  "_comment": "Spanish (ES) translation for Clarify - Community contributions welcome via GitHub",
  "_translators": ["Automated baseline translation - needs review"],
  "app.title": "Clarify - Sistema de gestión de archivos JSON",
  ...
}
```

## MVP Rationale

### Why Baseline Translations?
1. **Availability > Perfection**: Users need functionality now, perfection later
2. **Community Engagement**: Clear path for native speakers to contribute
3. **Technical Validation**: All infrastructure tested with multiple character sets
4. **User Impact**: International users can start using Clarify immediately

### Trade-offs
- **Accuracy**: Baseline translations may have minor errors → Community refinement path
- **Naturalness**: Automated translations may not sound native → Native speaker review needed
- **Context**: Some phrases may not fit UI context perfectly → User feedback will guide improvements

### Success Criteria
- ✅ All 5 languages functionally complete (240 keys each)
- ✅ All files valid JSON with proper encoding
- ✅ 100% test coverage passing
- ✅ No blocking issues for users
- ✅ Clear community contribution path documented
