## Overview

The **Reference Resolver** provides two modes for handling duplicate objects in JSON/TypeScript files:

1. **Delete Duplicates** (default): Remove duplicate objects entirely, keeping only the first occurrence
2. **Use References**: Replace duplicates with `$ref:path:line` references to the original

Additionally, it includes a **Resolve References** feature to expand existing `$ref` references back to their actual values.

---

## Architecture

### Execution Order

The Reference Resolver is integrated into the `cli_dedupe()` pipeline with the following order:

```
1. resolve_references() [if enabled]
   ↓
2. dedupe() + join_keys()
   ↓
3. create_references() OR remove_duplicate_objects()
   ↓
4. Other operations (exclude_numeric, skip_empty, etc.)
   ↓
5. enforce_consistent_case()
   ↓
6. Serialize and save
```

**Key Rule**: References must be **resolved BEFORE** creating new ones to avoid circular dependencies.

## Backend Implementation

### File: `src/rewriter/reference_resolver.py`

#### Function: `create_references()`

```python
def create_references(
    node: JSONNode,
    mode: str = 'delete',
    include_line_numbers: bool = True
) -> Tuple[JSONNode, Dict[str, int]]:
```

**Purpose**: Replace duplicate objects with references or delete them.

**Modes**:
- `'delete'`: Remove duplicates (legacy behavior)
- `'references'`: Replace duplicates with `$ref:path:line`

**Algorithm**:
1. Traverse JSON tree recursively
2. Build index of seen objects: `{frozen_value: (path, line, obj)}`
3. On duplicate detection:
   - Delete mode: Return `None` (removes from tree)
   - References mode: Return `"$ref:path:line"` string
4. First occurrence (lowest line) is always kept

**Output Formats**:
- With line numbers: `$ref:root.user.profile:42`
- Without line numbers: `$ref:root.user.profile`

**Return Stats**:
```python
{
    'created': 5,    # Number of references created
    'deleted': 3,    # Number of objects deleted
    'kept': 12       # Number of unique objects kept
}
```

---

#### Function: `resolve_references()`

```python
def resolve_references(node: JSONNode) -> Tuple[JSONNode, Dict[str, int]]:
```

**Purpose**: Expand `$ref` references to their actual values.

**Algorithm**:
1. Build path index: `{path: value}` for all objects in tree
2. Traverse tree, detect `$ref:...` strings
3. Parse reference format (supports with/without line numbers)
4. Lookup referenced value in index
5. Replace `$ref` string with actual object
6. Log warnings for invalid references

**Supported Formats**:
- `$ref:path.to.key:123` (with line number)
- `$ref:path.to.key` (without line number)

**Error Handling**:
- Invalid format → Warning + keep as-is
- Path not found → Warning + keep as-is

**Return Stats**:
```python
{
    'resolved': 8,   # Number of valid references expanded
    'invalid': 2     # Number of invalid references (warnings)
}
```

### Integration in `cli_dedupe()`

```python
# Step 1: Resolve existing refs FIRST
if args.resolve_references:
    obj, ref_stats = rw.resolve_references(obj)
    stats['references_resolved'] = ref_stats['resolved']
    stats['references_invalid'] = ref_stats['invalid']

# ... dedupe, join_keys ...

# Step 3: Create refs or delete duplicates
if args.remove_duplicate_objects:
    if args.use_references:
        # New reference resolver (Sprint A)
        obj, ref_stats = rw.create_references(obj, mode='references', include_line_numbers=True)
        stats['references_created'] = ref_stats['created']
    else:
        # Legacy remove_duplicate_objects (delete mode)
        obj, stats['duplicate_objects'], dup_stats = rw.remove_duplicate_objects(...)
```

## Known Limitations (Sprint A)

1. **Single-file only**: Cannot resolve references to other files
2. **One format**: Only `$ref:path` and `$ref:path:line` supported
3. **No relative paths**: All paths are absolute from root
4. **Non-recursive expansion**: References always point to original key (no cascading)
5. **No preview**: References created/resolved immediately without confirmation dialog

These limitations will be addressed in **Sprint B**.
