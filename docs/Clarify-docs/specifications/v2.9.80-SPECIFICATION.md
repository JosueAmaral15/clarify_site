## 📋 Overview

Implementação de suporte completo aos formatos **TOON** (Token-Oriented Object Notation) e **BSON** (Binary JSON), permitindo conversões bidirecionais entre JSON↔TOON↔BSON em grafo completo, com editor dedicado para TOON e suporte CLI para operações em lote.

### Problema Resolvido

**Antes**: Clarify trabalhava exclusivamente com JSON/TS/TSX, sem suporte para formatos alternativos como TOON (otimizado para LLMs) ou BSON (usado em MongoDB).

**Depois**: Usuários podem:
- Converter JSON ↔ TOON ↔ BSON (grafo completo: 6 direções)
- Abrir/editar arquivos `.toon` e `.bson` nativamente
- Reduzir 30-60% de tokens em prompts LLM usando TOON
- Importar/exportar dados MongoDB via BSON
- Converter em lote via CLI

## 🏗️ Architecture

### Design Patterns Aplicados

1. **Strategy Pattern (GoF)**:
   - `ConverterStrategy`: Interface abstrata para conversores
   - `JsonToToonConverter`, `ToonToJsonConverter`, etc. (6 implementações)

2. **Factory Pattern (GoF)**:
   - `ConverterFactory.create(from_format, to_format)`: Retorna conversor adequado
   - Centraliza lógica de seleção baseada em (origem, destino)

3. **Adapter Pattern (GoF)**:
   - `ToonAdapter`: Adapta interface `toon-llm` para API interna
   - `BsonAdapter`: Adapta `pymongo.bson` para API interna

4. **Facade Pattern (GoF)**:
   - `FormatConverter.convert(data, from_fmt, to_fmt)`: API simplificada
   - Esconde complexidade do grafo de conversões

5. **Low Coupling (GRASP)**:
   - Módulos independentes: `src/converters/toon.py`, `src/converters/bson.py`
   - Reutilizáveis fora do Clarify

6. **High Cohesion (GRASP)**:
   - Todas funcionalidades TOON em `toon.py`, BSON em `bson.py`

def test_toon_encode_simple_object():

### TOON Syntax Quick Reference

```toon
# Objects (key: value)
name: Alice
age: 30

# Arrays (inline)
tags[3]: python,coding,llm

# Arrays (tabular - most compact for LLMs)
users[2]:
  id,name,role
  1,Alice,admin
  2,Bob,user

# Nested
config:
  debug: true
  port: 8080
  hosts[2]: localhost,127.0.0.1
```
