## 📦 Componentes

### **1. Módulo Compartilhado** (`src/utils/advanced_conditions.py`)

**LOC**: 112 linhas

**Funções Exportadas**:

#### `get_conditions_from_ui(cond_rows) -> list[Condition]`
```python
"""
Build list of Condition objects from UI rows.
Skips empty rows (no field selected).

Args:
    cond_rows: List of tuples (combo_field, combo_op, ed_value, combo_scope, chk_case, chk_regex)
               Each tuple contains PySide6 widgets representing one condition row.

Returns:
    List of valid Condition objects (empty rows are skipped)
"""
```

**Lógica**:
- Itera sobre `cond_rows` (tuplas de widgets)
- Extrai: `field`, `operator`, `value`, `scope_type`, `case_sensitive`, `use_regex`
- Pula rows com campos vazios (`not field or not operator or not value`)
- Cria objetos `Condition` (importado de `src.core.filters`)
- Retorna lista de conditions válidas

#### `apply_conditions_to_files(files, conditions, logic_op, enabled) -> tuple[list[str], int]`
```python
"""
Apply advanced conditions to file list.

Args:
    files: List of file paths to filter
    conditions: List of Condition objects to apply
    logic_op: "AND" (all must match) or "OR" (at least one must match)
    enabled: Whether filtering is enabled (if False, returns all files unchanged)

Returns:
    Tuple of (filtered_files, num_filtered_out)
    - filtered_files: List of files that passed the filters
    - num_filtered_out: Number of files that were filtered out
"""
```

**Lógica**:
- Se `enabled=False`: retorna `(files, 0)` (sem filtro)
- Se `conditions` vazio: retorna `(files, 0)` (sem filtro)
- Chama `filter_files_by_conditions(files, conditions, logic_op)` (core module)
- Calcula `filtered_out = original_count - len(filtered_files)`
- Retorna `(filtered_files, filtered_out)`

def _apply_advanced_conditions(self, files: list[str]) -> tuple[list[str], int]:
    """Apply advanced conditions to file list.
    (Delegated to shared module for reusability)
    Returns: (filtered_files, num_filtered_out)
    """
    conditions = self._get_conditions()
    logic_op = self.combo_cond_logic.currentText()
    enabled = self.adv_cond_group.isChecked()
    
    return apply_conditions_to_files(files, conditions, logic_op, enabled)

#### **C. Integração com `cli_dedupe()`**

**Signature modificada**:
```python
def cli_dedupe(args: argparse.Namespace, 
               advanced_conditions: Optional[list[Condition]] = None, 
               apply_all_types: bool = False):
```

**Lógica ANTES de processar**:
```python
# Apply advanced filters BEFORE processing (Sprint B Feature #1)
if advanced_conditions:
    # Auto-detect JSON files unless apply_all_types is True
    input_file = args.input
    should_filter = apply_all_types or input_file.endswith(('.json', '.JSON'))
    
    if should_filter:
        # Apply filters
        filtered_files, filtered_out = apply_conditions_to_files(
            [input_file],
            advanced_conditions,
            logic_op="AND",
            enabled=True
        )
        
        stats['advanced_filters_filtered'] = filtered_out
        
        # If file was filtered out, skip processing (Q6: process all if zero files pass)
        if not filtered_files:
            # Return empty result (file was filtered out)
            return "", {}, stats
```

**Chamada no `_rewrite()`**:
```python

    ns,
    advanced_conditions=self.advanced_conditions if self.advanced_filters_enabled else None,
    apply_all_types=self.chk_apply_all_types.isChecked()
)
```

**Load (`_load_preferences()`)**:
```python
# Load advanced filters settings (Sprint B Feature #1)
if hasattr(self, 'chk_apply_all_types'):
    self.chk_apply_all_types.setChecked(settings.value("advanced_filters_apply_all_types", False, type=bool))
    self.advanced_filters_enabled = settings.value("advanced_filters_enabled", False, type=bool)
    
    # Load serialized conditions (JSON format)
    import json
    conditions_json = settings.value("advanced_filters_conditions", "[]", type=str)
    try:
        conditions_data = json.loads(conditions_json)
        self.advanced_conditions = [
            Condition(
                field=c['field'],
                operator=c['operator'],
                value=c['value'],
                scope_type=c.get('scope_type', 'none'),
                scope_value=c.get('scope_value', ''),
                case_sensitive=c.get('case_sensitive', True),
                whole_word=c.get('whole_word', False),
                use_regex=c.get('use_regex', False)
            )
            for c in conditions_data
        ]
    except (json.JSONDecodeError, KeyError):
        self.advanced_conditions = []
```
