## 📋 Visão Geral

Sistema automatizado de testes de carga para identificar limites de performance e gargalos do Clarify em cenários de uso intensivo. Complementa o sistema de benchmarks (v2.9.81) com testes de stress em operações paralelas.

**Objetivo**: Documentar limites reais do sistema para guiar otimizações e definir requisitos de hardware.

---

## 🎯 Requisitos Funcionais

### RF1: Cenários de Carga Realistas
- **Cenário 1**: Processar 1000+ arquivos JSON simultaneamente (operação batch)
- **Cenário 2**: Set Operations (union/intersection) com 100+ arquivos grandes
- **Cenário 3**: Search em corpus de 5-10GB (milhares de arquivos)
- **Cenário 4**: Rewriter em operações massivas (deduplicate/normalize)

### RF2: Métricas de Performance
- **Throughput**: Arquivos processados/segundo
- **Latência**: Tempo médio por operação (min/max/p50/p95/p99)
- **Recursos**: CPU usage (%), RAM usage (MB), Disk I/O (MB/s)
- **Concorrência**: Número máximo de workers simultâneos
- **Taxa de erro**: Falhas/timeouts (%)

### RF3: Simulação de Carga Progressiva
- **Warmup**: 10% da carga (aquecimento do sistema)
- **Ramp-up**: Aumento gradual de 10% → 100% em 30s
- **Sustentação**: Carga máxima por 60s
- **Cooldown**: Redução gradual para monitorar recuperação

### RF4: Detecção de Limites
- **CPU Saturation**: Detectar quando CPU > 95% sustentado
- **Memory Pressure**: Avisar quando RAM > 90% disponível
- **Disk I/O Bottleneck**: Identificar saturação de disco
- **Thrashing**: Detectar degradação de performance (latência > 2x baseline)

### RF5: Relatório Detalhado
- **Console**: Progresso em tempo real com barra de progresso
- **JSON**: Resultados completos salvos em `load_tests/results/`
- **Markdown**: Relatório executivo em `docs/PERFORMANCE.md`
- **Comparação**: Histórico de execuções (versões anteriores)

## 🔧 Uso do Sistema

### CLI Runner

```bash
# Executar todos os cenários
python -m load_tests --all

# Executar cenário específico
python -m load_tests --scenario batch_processing --files 1000

# Executar com configuração personalizada
python -m load_tests --scenario set_operations \
    --files 100 \
    --workers 8 \
    --duration 60 \
    --output results/custom_test.json

# Gerar relatório markdown
python -m load_tests --generate-report results/v2.9.82_20241221.json
```

### API Programática

```python
from load_tests import LoadRunner, Scenarios, LoadConfig

# Configurar teste
config = LoadConfig(
    num_workers=8,
    warmup_duration=10,
    rampup_duration=30,
    sustain_duration=60,
    cooldown_duration=20
)

# Criar runner
runner = LoadRunner(config)

# Executar cenário
result = runner.run_scenario(
    Scenarios.batch_file_processing,
    num_files=1000
)

# Analisar resultados
print(f"Throughput: {result.throughput:.2f} files/sec")
print(f"Latency p95: {result.latency_p95:.0f}ms")
print(f"Status: {result.status}")
```
