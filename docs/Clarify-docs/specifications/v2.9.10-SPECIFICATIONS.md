## Task #21 - Substituir Listas por Objetos {#task-21}

### 📝 Descrição
Converter arrays JSON em objetos/dicionários com chaves geradas automaticamente a partir dos valores.

### 🎯 Exemplo

**Input:**
```json
{
  "messages": [
    "O usuario pode seguir com as intruções mencionadas",
    "Pesquisa alternativa"
  ]
}
```

**Output:**
```json
{
  "messages": {
    "oUsuarioPodeSeguir": "O usuario pode seguir com as intruções mencionadas",
    "pesquisaAlternativa": "Pesquisa alternativa"
  }
}
```

### 🔧 Especificações Técnicas

#### Geração de Chaves
- **Default**: Primeiros 30 caracteres do valor
- **Parâmetro usuário**: `key_max_chars` (configurável)
- **Formato**: camelCase (default, configurável via `key_case_style`)
- **Limpeza**: Remover acentos e caracteres especiais
- **Algoritmo**:
  ```python
  1. Pegar primeiros N caracteres do valor
  2. Dividir em palavras
  3. Remover acentos: "usuário" → "usuario"
  4. Remover especiais: mantém apenas [a-zA-Z0-9]
  5. Converter para camelCase: "O usuario pode seguir" → "oUsuarioPodeSeguir"
  6. Limitar comprimento máximo
  ```

#### Resolução de Conflitos
**Regra Principal**: NÃO criar sufixos numéricos para conflitos de nomes

**Cenários**:

1. **Chaves iguais, MESMO pai, valores DIFERENTES**:
   ```json
   // Não mexer!
   {
     "items": {
       "userMessage": "Bem vindo",
       "userMessage": "Ola"  // Mantém ambos (erro JSON, mas não é responsabilidade desta feature)
     }
   }
   ```

2. **Chaves iguais, MESMO pai, valores IGUAIS (redundantes)**:
   ```json
   // ANTES
   {
     "items": [
       "Bem vindo",
       "Bem vindo"  // Redundante
     ]
   }
   
   // DEPOIS (se eliminate_duplicates=True)
   {
     "items": {
       "bemVindo": "Bem vindo"  // Apenas uma entrada
     }
   }
   ```

3. **Chaves iguais, pais DIFERENTES, valores IGUAIS**:
   ```json
   // ANTES
   {
     "t": {
       "pages": {
         "contact": {"lookingForQuickAnswers": "Looking for quick answers?"},
         "contactPage": {"lookingForQuickAnswers": "Looking for quick answers?"}
       }
     }
   }
   
   // DEPOIS (se eliminate_duplicates=True)
   {
     "t": {
       "pages": {
         "contact": {"lookingForQuickAnswers": "Looking for quick answers?"}
         // contactPage.lookingForQuickAnswers removido (linha maior/mais abaixo)
       }
     }
   }
   ```

4. **Conflito ao gerar: pegar mais palavras**:
   ```python
   # Se "O usuario pode..." gera "oUsuarioPode"
   # E "O usuario poderia..." também gera "oUsuarioPode"
   # Solução: Pegar mais palavras até diferenciar
   # "oUsuarioPodeSeguir" vs "oUsuarioPoderiaContinuar"
   ```

## Task #22 - Normalizar Escaping {#task-22}

### 📝 Descrição
Detectar e corrigir excesso de escaping em valores JSON/TS.

### 🎯 Exemplo

**Problema**:
```javascript
retelllecture: '\'RetellLecture\', \'Retell Lecture\', \'Re-tell Lecture\','
//              ^^ Excesso de escaping
```

**Correção**:
```javascript
// Opção 1: Normalizar para aspas simples
retelllecture: "'RetellLecture', 'Retell Lecture', 'Re-tell Lecture',"

// Opção 2: Normalizar para aspas duplas (preferível)
retelllecture: "\"RetellLecture\", \"Retell Lecture\", \"Re-tell Lecture\","
```

### 🔧 Especificações Técnicas

#### Detecção Automática

**Níveis de Escaping**:
```python
# Nível 0: OK (desejado)
value = "It's working"  # OK
value = 'It\'s working'  # OK

# Nível 1: OK (desejado)
value = "\"quoted\""  # OK
value = '\'quoted\''  # OK

# Nível 2+: PROBLEMA (excesso)
value = '\\'quoted\\''   # ❌ Excesso: \\ → \
value = '\\\\'text\\\\' # ❌ Excesso: \\\\ → \
value = '\\\'text\\\''  # ❌ Excesso: \\' → '
```

**Algoritmo de Detecção**:
```python
import re

def detect_escape_excess(value: str) -> bool:
    """
    Detecta se há excesso de escaping (múltiplos backslashes).
    
    Padrões problemáticos:
    - \\' ou \\" (duplo escape)
    - \\\' ou \\\" (triplo escape)
    - E assim por diante
    """
    # Padrão: 2+ backslashes seguidos de quote
    pattern = r'\\{2,}[\"\']'
    return bool(re.search(pattern, value))

def normalize_escape_excess(value: str, target_quote: str = '"') -> str:
    """
    Remove níveis excessivos de escaping.
    
    Args:
        value: String com possível excesso de escaping
        target_quote: '"' ou "'" - tipo de aspas desejado
    
    Returns:
        String normalizada
    
    Examples:
        normalize_escape_excess("\\'text\\'", '"')  → "\"text\""
        normalize_escape_excess("\\\\'text\\\\'", '"') → "\"text\""
    """
    # Remover escapes excessivos iterativamente
    while True:
        original = value
        # Remover duplo escape: \\ → \
        value = value.replace('\\\\', '\\')
        # Se não houve mudança, parar
        if value == original:
            break
    
    # Normalizar para o tipo de aspas desejado
    if target_quote == '"':
        # Converter aspas simples para duplas
        value = value.replace("\\'", "'")  # Remover escape de '
        value = value.replace('"', '\\"')   # Escapar "
        value = value.replace("'", '"')     # Trocar ' por "
    else:
        # Manter aspas simples
        value = value.replace('\\"', '"')   # Remover escape de "
        value = value.replace("'", "\\'")   # Escapar '
    
    return value
```

## Task #23 - Atualizar Referências Órfãs {#task-23}

### 📝 Descrição
Ao eliminar chaves redundantes do dicionário JSON, atualizar automaticamente as referências em arquivos JSX/TSX que referenciam chaves removidas.

### 🎯 Cenário Completo

**Passo 1: Dicionário ANTES** (`en.ts`):
```typescript
export const en = {
  pages: {
    contact: {
      lookingForQuickAnswers: "Looking for quick answers? Check out our"  // linha 44
    },
    contactPage: {
      lookingForQuickAnswers: "Looking for quick answers? Check out our"  // linha 266 (redundante)
    }
  }
}
```

**Passo 2: Arquivo JSX** (`page.tsx`):
```tsx
function ContactPage() {
  const {t} = useTranslation();
  
  return (
    <div>
      <h1>{t.pages.contactPage.lookingForQuickAnswers}</h1>
      {/* ^^^ Referência que ficará órfã */}
    </div>
  );
}
```

**Passo 3: Eliminar duplicatas** → `contactPage.lookingForQuickAnswers` removido (linha maior)

**Passo 4: PROBLEMA**:
```tsx
// page.tsx agora tem referência órfã
<h1>{t.pages.contactPage.lookingForQuickAnswers}</h1>
//   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ undefined!
```

**Passo 5: SOLUÇÃO AUTOMÁTICA**:
```tsx
// Substituir automaticamente
<h1>{t.pages.contact.lookingForQuickAnswers}</h1>
//   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ Referência válida
```

### 🔧 Especificações Técnicas

#### Fluxo de Trabalho

```
1. Usuário marca "Update references in project files"
2. Usuário informa diretório de arquivos (.tsx/.jsx)
3. ANTES de eliminar duplicatas:
   a. Scan todos arquivos no diretório
   b. Detectar todas referências ao dicionário
   c. Construir mapa de referências
4. DURANTE eliminação de duplicatas:
   a. Para cada chave removida, registrar substituição
   b. Manter mapa: chave_removida → chave_mantida
5. APÓS eliminação:
   a. Aplicar substituições em todos arquivos
   b. Salvar backup (.bak)
   c. Gerar log de mudanças (se solicitado)
6. Preview (opcional):
   a. Mostrar todas substituições antes de aplicar
   b. Usuário pode aceitar/rejeitar
```

#### Detecção de Referências

**Padrões Regex**:
```python
import re

# Padrão 1: Template literals
# {t.pages.contact.title}
pattern_template = r'\{t\.([A-Za-z0-9_]+(?:\.[A-Za-z0-9_]+)*)\}'

# Padrão 2: Propriedades JSX
# {t.pages.contact.title}
pattern_jsx = r'\{t\.([A-Za-z0-9_]+(?:\.[A-Za-z0-9_]+)*)\}'

# Padrão 3: Acesso direto
# t.pages.contact.title
pattern_direct = r'\bt\.([A-Za-z0-9_]+(?:\.[A-Za-z0-9_]+)*)\b'

def extract_all_references(content: str) -> list[str]:
    """
    Extrai todas as referências ao dicionário de tradução.
    
    Returns:
        Lista de paths completos (ex: ["pages.contact.title", "common.buttons.next"])
    """
    refs = set()
    
    # Aplicar todos os padrões
    for pattern in [pattern_template, pattern_jsx, pattern_direct]:
        for match in re.finditer(pattern, content):
            refs.add(match.group(1))
    
    return sorted(refs)
```

**Scan de Arquivos**:
```python
def scan_project_references(directory: str, extensions: list[str]) -> dict[str, list[str]]:
    """
    Scan todos arquivos e extrai referências.
    
    Args:
        directory: Diretório raiz do projeto
        extensions: Lista de extensões (ex: ['.tsx', '.jsx', '.ts', '.js'])
    
    Returns:
        Dicionário: {filepath: [refs]}
    """
    file_refs = {}
    
    for root, dirs, files in os.walk(directory):
        for file in files:
            if any(file.endswith(ext) for ext in extensions):
                filepath = os.path.join(root, file)
                content = read_text(filepath)
                refs = extract_all_references(content)
                if refs:
                    file_refs[filepath] = refs
    
    return file_refs
```

#### Aplicação de Substituições

```python
def apply_substitutions_to_file(
    filepath: str,
    substitutions: dict[str, str],
    backup: bool = True
) -> int:
    """
    Aplica substituições em um arquivo.
    
    Args:
        filepath: Caminho do arquivo
        substitutions: Mapa de substituições
        backup: Se True, cria .bak antes de modificar
    
    Returns:
        Número de substituições aplicadas
    """
    content = read_text(filepath)
    original_content = content
    count = 0
    
    # Ordenar por comprimento (maior primeiro) para evitar substituições parciais
    sorted_subs = sorted(
        substitutions.items(), 
        key=lambda x: len(x[0]), 
        reverse=True
    )
    
    for old_path, new_path in sorted_subs:
        # Padrão 1: {t.old.path} → {t.new.path}
        pattern1 = r'\{t\.' + re.escape(old_path) + r'\}'
        replacement1 = '{t.' + new_path + '}'
        content, n1 = re.subn(pattern1, replacement1, content)
        
        # Padrão 2: t.old.path → t.new.path (não dentro de {})
        pattern2 = r'\bt\.' + re.escape(old_path) + r'\b'
        replacement2 = 't.' + new_path
        content, n2 = re.subn(pattern2, replacement2, content)
        
        count += n1 + n2
    
    if content != original_content:
        if backup:
            safe_backup_file(filepath)
        write_text(filepath, content)
    
    return count
```

- ✅ Menu items, dock titles, tooltips, dialogs
- ✅ Mensagens de erro/sucesso

#### Sistema de Tradução

**translator.py**:
```python
"""
i18n Translation System for Clarify GUI
"""

import json
import os
from typing import Any, Optional
from pathlib import Path

class Translator:
    """
    Lightweight translation system for Clarify.
    Loads translations on demand and supports runtime language switching.
    """
    
    def __init__(self, default_lang: str = "en"):
        self.current_lang = default_lang
        self.translations: dict[str, dict] = {}
        self.base_dir = Path(__file__).parent
        
        # Auto-detect system language
        self._detect_system_language()
        
        # Load default language
        self.load_language(self.current_lang)
    
    def _detect_system_language(self):
        """Detect system language and set as default if supported."""
        import locale
        try:
            system_lang = locale.getdefaultlocale()[0]  # e.g., 'pt_BR', 'en_US'
            if system_lang:
                lang_code = system_lang.split('_')[0]  # 'pt', 'en'
                if lang_code in ['pt', 'en']:
                    self.current_lang = lang_code if lang_code == 'en' else 'pt_BR'
        except Exception:
            self.current_lang = "en"  # Fallback
    
    def load_language(self, lang: str) -> bool:
        """
        Load translation file for specified language.
        
        Args:
            lang: Language code ('en', 'pt_BR')
        
        Returns:
            True if loaded successfully
        """
        if lang in self.translations:
            return True  # Already loaded
        
        file_path = self.base_dir / f"{lang}.json"
        if not file_path.exists():
            print(f"Translation file not found: {file_path}")
            return False
        
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                self.translations[lang] = json.load(f)
            return True
        except Exception as e:
            print(f"Error loading translation {lang}: {e}")
            return False
    
    def switch_language(self, lang: str) -> bool:
        """
        Switch to a different language.
        
        Args:
            lang: Language code ('en', 'pt_BR')
        
        Returns:
            True if switched successfully
        """
        if self.load_language(lang):
            self.current_lang = lang
            return True
        return False
    
    def get(self, key: str, **kwargs) -> str:
        """
        Get translated string by key path.
        
        Args:
            key: Dot-separated path (e.g., 'menu.file.exit')
            **kwargs: Format parameters (e.g., value=50 for 'Current: {value}%')
        
        Returns:
            Translated string or key itself if not found
        
        Examples:
            tr.get('menu.file.exit')  → "Sair"
            tr.get('dialogs.transparency.current', value=75)  → "Atual: 75%"
        """
        # Fallback chain: current_lang → 'en' → key itself
        for lang in [self.current_lang, 'en']:
            if lang not in self.translations:
                continue
            
            # Navigate nested dict
            value = self.translations[lang]
            for part in key.split('.'):
                if isinstance(value, dict) and part in value:
                    value = value[part]
                else:
                    value = None
                    break
            
            if isinstance(value, str):
                # Apply formatting if kwargs provided
                try:
                    return value.format(**kwargs) if kwargs else value
                except KeyError:
                    return value
        
        # Fallback: return key itself
        return key
    
    def __call__(self, key: str, **kwargs) -> str:
        """Shorthand for get()."""
        return self.get(key, **kwargs)


# Global translator instance
_translator: Optional[Translator] = None

def get_translator() -> Translator:
    """Get global translator instance (singleton)."""
    global _translator
    if _translator is None:
        _translator = Translator()
    return _translator

def tr(key: str, **kwargs) -> str:
    """Shorthand function for translation."""
    return get_translator().get(key, **kwargs)
```
