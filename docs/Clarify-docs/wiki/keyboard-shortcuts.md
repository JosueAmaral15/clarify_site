## ⚙️ Customizing Shortcuts

### How to Change Shortcuts

1. **Open Settings**: `Ctrl+,` / `Cmd+,`
2. **Go to Keyboard Shortcuts**: `Settings → Keyboard Shortcuts`
3. **Search for action**: Use search box to filter
4. **Click shortcut**: Click existing shortcut to edit
5. **Press new keys**: Type your desired combination
6. **Save**: Click "Save" or press Enter

### Shortcut Rules

- **Modifiers**: Must use `Ctrl`/`Cmd`, `Shift`, `Alt`/`Option`
- **Conflicts**: System warns if shortcut already used
- **Reserved**: Some OS shortcuts can't be changed (e.g., `Cmd+Q` on macOS)
- **Reset**: "Reset to Default" button restores original shortcuts

### Export/Import Shortcuts

Save your custom shortcuts to share or backup:

```bash
# Export
Settings → Keyboard Shortcuts → Export → shortcuts.json

# Import
Settings → Keyboard Shortcuts → Import → Select shortcuts.json
```

## 💡 Tips & Best Practices

### Essential Shortcuts to Learn First

Master these 10 shortcuts for 80% of daily work:

1. **`Ctrl+O`** - Open file (use constantly)
2. **`Ctrl+S`** - Save (muscle memory!)
3. **`Ctrl+F`** - Find (search within file)
4. **`Ctrl+Shift+F`** - Find in files (project-wide)
5. **`Ctrl+E`** - Toggle editor (quick access)
6. **`Ctrl+Shift+R`** - JSON Rewriter (cleaning)
7. **`Ctrl+Shift+A`** - AI Processor (refactoring)
8. **`Ctrl+Z/Y`** - Undo/Redo (safety net)
9. **`Ctrl+Tab`** - Switch docks (navigation)
10. **`Ctrl+,`** - Settings (customization)

### Shortcuts by Task

**Quick File Cleanup**:
1. `Ctrl+O` - Open file
2. `Ctrl+Shift+R` - Open rewriter
3. `Ctrl+Alt+D` - Deduplicate
4. `Ctrl+Enter` - Run
5. `Ctrl+S` - Save

**Batch Search/Replace**:
1. `Ctrl+Shift+F` - Open search
2. Type pattern
3. Preview matches
4. `Ctrl+Shift+H` - Replace all
5. `Ctrl+S` - Save

**AI Refactoring**:
1. `Ctrl+Shift+A` - Open AI
2. `Ctrl+T` - Load template
3. Edit prompt
4. `Ctrl+Enter` - Run
5. Review results
