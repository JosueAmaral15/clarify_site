                           KEY CONCEPTS

1. ENTRY POINTS (What users run):
   • clarify.py          → Most intuitive for users
   • python -m src       → Standard Python convention
   • clarify_gui.sh/bat  → GUI convenience (one click)

2. THE REAL CODE (Where logic lives):
   • src/app.py          → Main application (~2,700 lines)
   • src/core/           → Core functionality
   • src/utils/          → Utilities
   • src/rewriter/       → JSON processing

3. DEVELOPMENT TOOLS (For developers):
   • main.py             → Test module architecture
   • tests/              → Unit tests (future)

4. WHY MULTIPLE ENTRY POINTS?
   • clarify.py          → User expectation/convenience
   • src/__main__.py     → Python standard
   • main.py             → Development testing
